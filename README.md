## ABOUT THIS ARCHIVE

This repository documents my ongoing practice
throughout the MFA Computational Arts programme
at Goldsmiths.

It brings together reflections, feedback,
visual research, reading, and creative experiments.

Rather than presenting only finished work,
this archive also records the process of
exploring and developing ideas.
